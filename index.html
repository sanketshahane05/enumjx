Status enum

Members keep identity across lookup and aliases. Metadata and JSON are attached to each member.

const Status = Enums.Status('Active', 'Pending');
Status.Active === Status.fromName('active');

Combined API commands

      
Ordinary enum members can be combined. Combinations stay immutable and belong to their enum.

      
const bits = APICommand.bitwise();
const access = bits.combine([APICommand.Start, APICommand.Stop]);

      

    

    

      
Permission flags

      
With .flags(), individual member values are powers of two.

      
const Permission = Enums.Permission.flags('Read', 'Write', 'Delete');
